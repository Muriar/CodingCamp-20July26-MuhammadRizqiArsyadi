## ⚠️ Required Features (MVP)
Your project must include:
Input Form
Fields: Item Name, Amount, Category (Food, Transport, Fun)
Add a transaction to the list when submitted
Validate that all fields are filled
Transaction List
Scrollable list of all added items
Show name, amount, and category
Ability to delete items
Total Balance
Display total balance at the top
Updates automatically when items are added or deleted
Visual Chart
Pie chart showing spending distribution by category
Chart updates automatically when items change
You can use Chart.js or another simple chart library


## Technical Constraints
TC-1: Technology Stack
HTML for structure
CSS for styling
Vanilla JavaScript (no frameworks like React, Vue, etc.)
No backend server required


TC-2: Data Storage
Use browser Local Storage API
All data stored client-side only


TC-3: Browser Compatibility
Must work in modern browsers (Chrome, Firefox, Edge, Safari)
Can be used as standalone web app or browser extension


## Non-Functional Requirements
NFR-1: Simplicity
Clean, minimal interface
Easy to understand and use
No complex setup required
No test setup required


NFR-2: Performance
Fast load time
Responsive UI interactions
No noticeable lag when updating data


NFR-3: Visual Design
User-friendly aesthetic
Clear visual hierarchy
Readable typography

##  Folder Rules
Only 1 CSS file inside css/
Only 1 JavaScript file inside js/
Keep code clean and readable
